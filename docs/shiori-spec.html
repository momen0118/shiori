旅のしおり

家族旅行のしおりを作って、旅行中に見て、その場で予定を変えられる個人用ツール。この仕様書は会議で決めたことをまとめたもので、Claude Code はこれと FORMAT.md をもとに作る。

1大事にすること

  • 主役は旅行中。開いたらすぐ「今どこか」がわかって、予定はその場で気軽に変えられる。
  • 書いても書かなくてもいい。必須は名前だけ（しおりのタイトル、立ち寄りの名前、いけたらいくの名前）。それ以外は全部空けてよく、空いている欄やボタンは画面に出さない。計画は楽しく、義務にはしない。
  • 作るのは自分だけ。夫には送ったリンクで見てもらうだけで、夫の側には何も保存しない。
  • ダークモードが基本。ライトモードも同じ手間で整える。ふだんは iPhone の設定に合わせて切り替わり、本棚のメニューの「画面の色」でダーク・ライトに固定もできる（その iPhone だけの設定）。
  • 見た目は旅行アプリのようにすっきり。ただし表紙とページめくりでしおりらしさを出す。紙に寄せすぎない。

3本棚と思い出の棚

アプリを開いたときのホーム画面。しおりの表紙を並べた本棚。

  • 表紙を2列で並べる。冊数は多くならないので、背表紙ではなく表紙で見せる。
  • 旅行中のしおり（今日が開始日〜終了日に入っているしおり）があれば一番上に大きく出す。タップでその日の行程ページへ。
  • その下に計画中のしおり。開始日が近い順、日付のないしおりは最後。「新しいしおり」ボタンは上に置く。
  • 一番下に「思い出の棚（n冊）」の入口。タップすると別の画面で、しまったしおりが並ぶ。
  • 「済み」はただの分類で、いつでも付けたり外したりできる。メニューの「思い出の棚にしまう」で思い出の棚へ移り、「本棚に戻す」で本棚に戻る。しまっても編集はできる（ロックしない）。ハンコなどの印は付けない。
  • 右上のメニュー：Claude から読み込む（新しいしおりとして）、全部まとめてバックアップ、バックアップから戻す、画面の色（自動・ダーク・ライト）。

新しいしおりを作るとき

  • 入れるのはタイトルだけでいい。日付、表紙の柄と色はあとからでも変えられる。
  • 持ち物を前のしおりからコピーするか選ぶ（6 持ち物）。

4しおりの中の共通ルール

  • ページの順番：表紙 → 持ち物 → 1日目 … n日目 → 行き先 → メモ。日数は開始日〜終了日から決まる。最後の日のページの一番下の「＋ n日目を追加」で日を足せる（日付があれば最終日も1日延びる）。
  • 左右のスワイプで紙をめくるような演出でページが変わる。ページの中は縦にスクロールできる（紙なのに縦に伸びるのは気にしない）。動きを減らす設定の iPhone では、めくりの演出を控えめにする。
  • 画面の右端に縦書きのインデックスタブ。タップでそのページへ一発で飛ぶ。今いるページのタブはしおりの色。
  • 並べ替えは、行の左の「つまみ」を掴んだときだけ動く。ページめくりのスワイプとぶつからないようにするため。
  • しおりを開いたとき：旅行中なら今日の行程ページから。それ以外は表紙から。
  • 表紙で選んだ色が、そのしおり全体のアクセント色になる（タブ、見出し、「いまここ」の枠、ボタン）。
  • しおりのメニュー：Claude 用に書き出す、Claude から読み込む（置き換え・いけたらいくだけ足す）、置き換える前に戻す、送る（夫に送る）、思い出の棚にしまう／本棚に戻す、しおりを消す。
  • 文字は、タイトルと見出しだけ丸ゴシック（iPhone 内蔵の「ヒラギノ丸ゴ」）で少し柔らかく、本文はふつうのゴシック（iPhone 内蔵の「ヒラギノ角ゴ」）で読みやすく。外部のフォントは読み込まないので、電波がなくても同じ見た目になる。

5表紙

  • 背景は柄8種類 × 色8色から選ぶ（64通り）。写真や画像は使わず、CSS で描く。データには柄と色の名前だけが入るので、夫に送るリンクにもそのまま載る。
  • 柄：チェック、ギンガム、ストライプ、ボーダー、水玉、方眼、波線、斜線。
  • 色：柿、山吹、若草、青磁、藍、藤、桜、鼠。ダークモードでは柄を暗く沈めて、眩しくならないようにする。
  • 載せるもの：タイトル、日付、行き先、ひとこと。タイトル以外は空でよく、空なら出さない。
  • 文字は本の題箋のような札に載せる。どの柄の上でも読めるようにするため。
  • 表紙のメニューから、柄と色を変える、思い出の棚にしまう／本棚に戻す。

6持ち物

  • 分類なし。1行1項目のシンプルなリスト。その場で追加・名前の修正・削除・並べ替え（つまみ）ができる。
  • まとめて追加：改行区切りのテキストを貼ると、1行ずつ別の項目として入る。Claude と洗い出したリストもこれで一気に入れられる。
  • リマインダー用にコピー：「・」や「-」などの記号を付けず、項目名だけを改行区切りでコピーする。iPhone のリマインダーのリストに貼ると1行1項目になる（実機で確認済み。メモアプリはチェックリストにならなかったのでリマインダーを使う）。
  • しおりの中ではチェックしない。チェックはリマインダーでする。
  • テンプレの仕組みは作らない。新しいしおりを作るときに「前のしおりから持ち物をコピー」する。コピー元は選べて、初期値は直近のしおり。取り込む前に一覧が出て、今回いらない物は外してから取り込める。
  • 夫に送ったしおりの持ち物ページにも、同じコピーボタンを置く。

7行程

  • 1日1ページ。見出しは「n日目」と日付・曜日。
  • 左に時刻、右に立ち寄りの箱、箱と箱の間に移動。箱の高さは時間に比例させない（中身に合わせる）。
  • 旅行中は、今の時刻にあたる箱に「いまここ」としおりの色の枠を付ける（開始〜終了の間。終了がなければ次の予定の開始まで）。

予約あれば箱に「予約」ボタン。8 予約

移動

  • 手段（初期値は車）と道のメモ（例：〇〇道経由）だけを入れる。
  • 所要時間は、前の予定の終了時刻と次の予定の開始時刻から自動で出す。前の予定に終了時刻がなければ開始時刻を終了とみなす（例：出発 07:30 → 次が 10:30 なら 3時間）。前の予定の時刻か次の予定の開始が空なら出さない。
  • ナビ開始ボタンは付けない。地図は立ち寄りの箱から開く。

旅行中に予定を変える

  • ここから後ろをずらす：遅れたときに、選んだ予定から後ろ（その日の中）の時刻をまとめて何分かずらす。
  • 予定の追加・削除・並べ替え（つまみ）・時刻の修正はその場でできる。
  • 行き先ページの「いけたらいく」から行程に入れられる（9 行き先）。

8予約

  • 予約は立ち寄りにひもづく。施設名と日時は立ち寄りの箱から引くので、二重に入力しない。
  • 行程の「予約」ボタンを押すと、下から小窓が出る。ページは移動しない。項目が少ないので折りたたみはなし。
  • 予約の一覧は、行き先ページの「予約あり」で絞り込んで見る。

9行き先

  • 行程の立ち寄りを全部、行程の順に並べる。日付や時刻の見出しで区切らず、各行に小さく「1日目 10:00」と添える。
  • 行をタップすると、その日の行程ページの該当の箱へ飛ぶ。
  • 絞り込み：すべて／予約あり。「予約あり」が予約一覧の代わり。

いけたらいく

  • ページの下の方に置く。「＋ お店や場所を追加」を押すと、名前・サイト・地図の3つの欄の小窓が出る（名前の欄にすぐ入力できる）。名前だけでも追加できる。
  • 項目をタップすると「行程に入れる」と、サイトも地図も空なら「URLを追加」、どちらかが入っていれば「修正」が出る。「行程に入れる」は、何日目かを選ぶ（旅行中は今日が初期値）→ 時刻を入れる（空でよい）→ 時刻があればその位置に、なければその日の最後に入る。
  • 行程に入れたら、いけたらいくの欄から消えて上の一覧に移る。サイトURLと地図URLは、そのまま箱のサイト・地図に移す。
  • 思い出の棚にしまっても、行かなかったいけたらいくはそのまま残す。

10メモ

  • しおりごとの自由なメモ欄。行程の箱のメモとは別。
  • メモのページはそのまま書き込める（「編集」ボタンなし。書いたそばから保存）。中に書いた URL と電話番号は、欄の下にボタンで並べて、タップで開ける・かけられる。行程の箱のメモ・予約のメモは、本文の中でタップできる。

11保存とバックアップ

  • データは IndexedDB に保存する。しおり1冊を FORMAT.md の形の JSON ひとかたまりとして持つ。将来、夫との同期を足したくなったら、保存先を差し替えるだけで済むようにしておく。
  • PWA にする（manifest と service worker）。ホーム画面から開けて、電波がなくてもしおりが見られる。
  • iPhone の Safari には、しばらく開かないサイトのデータを消す仕組みがある。自分の環境では今まで消えたことはないが、念のためホーム画面に追加して使う前提にして、バックアップも付ける。
  • バックアップ：本棚のメニューから、全部のしおりをまとめて1つの JSON として書き出す（ファイルに保存、またはコピー）。同じものから戻せる。
  • Claude からの JSON でしおりを置き換えるときは、置き換える前の状態をしおりごとに1つ控えておき、メニューから戻せるようにする。

12夫に送る

  • しおりのメニューの「送る」で、しおりまるごとを JSON → 圧縮して、リンクの # 以降に入れる。iPhone の共有シートを開いて LINE で送る。
  • # 以降はサーバーに送られないので、データはどこにも保存されない。リンクを知っている人なら見られるが、LINE で夫に送るだけなので問題にしない。
  • 受け取った側は、同じサイトでしおりを見るだけ。何も保存しない。見たいときはまたリンクを開く。上の方に「送られたしおり（見るだけ）」とわかる帯を出す。
  • 受け取り画面でも、持ち物の「リマインダー用にコピー」は使える。Gmail のボタン（自分のメールを開くもの）は出さない。
  • 表紙は柄と色の名前だけ入るので、同じ表紙で見える。
  • リンクの中身は送った時点のもの。予定を変えたら送り直す。

13Claude とのやりとり

形式は JSON。項目の定義と Claude が守るルールは FORMAT.md にまとめてある。

書き出し

今のしおりを JSON にしてコピーする。Claude に貼って相談するため。

読み込み（3種類）

  • 新しいしおりとして（本棚のメニューから）
  • 今のしおりと置き換え（控えを1つ残す）
  • いけたらいくだけ足す
  • テキストの貼り付けが基本。ファイルからも読める。コードブロックの記号ごと貼っても読めるようにする。
  • 読み込む前に中身の確認を出す（例：2日間・立ち寄り6件・予約1件・いけたらいく1件）。形がおかしいときは、どこがおかしいかを平易な言葉で出す。
  • 旅行中の組み直しの流れ：しおりで書き出し → Claude に貼って「雨なので2日目の午後を組み直して」→ 返ってきた JSON を「置き換え」で読み込む。
  • Claude 側は「旅の相談」用のプロジェクトを作り、FORMAT.md をナレッジに入れ、指示文（FORMAT.md の冒頭）を貼っておく。

14作るときに実機で確かめること

  • 確認済みGmail は googlegmail:///search?q= だと「リンクが開けませんでした」になるので、予約番号をコピーして googlegmail:// でアプリを開くだけにした。
  • 要確認夫に送るリンクの長さ。2泊くらいのしおりを LINE で送って、途中で切れないか。
  • 要確認ホーム画面から開いたときに、地図・Gmail・サイト（Chrome）のリンクがちゃんと外のアプリで開くか。
  • 要確認ページめくりのスワイプと、縦スクロール・つまみでの並べ替えがぶつからないか。
  • 要確認開始時刻なしの予定。使ってみて要らなければなくす。

15やらないこと

  • 夫との同期、夫の書き込み、ログインやアカウント
  • 写真や画像の表紙
  • ナビ開始ボタン、地図の検索リンクの自動生成
  • しおりの中での持ち物チェック、ショートカットアプリとの連携
  • 持ち物の分類、テンプレの仕組み
  • 予約の種類分け、人数・電話・料金・支払いなどの欄
  • 済みのロック、済みのハンコ
  • 緊急連絡先、天気
