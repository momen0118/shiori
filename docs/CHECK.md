# iPhone 実機で確かめること

仕様書の「作るときに実機で確かめること」と、パソコンの中では確かめられなかったことの手順です。
おかしかったら、どの番号で、どうなったかを教えてください。

## 0. 準備

1. GitHub のリポジトリの Settings → Pages で、公開するブランチ（ふだんは `main`）と `/ (root)` を選ぶ
2. 数分後に出る `https://ユーザー名.github.io/shiori/` を iPhone の Safari で開く
3. 共有ボタン →「ホーム画面に追加」。以降はホーム画面のアイコンから開く
4. テスト用に、しおりを1冊作っておく（Claude から読み込むのが早い。2泊くらい・予約2件・地図リンク付き）

## 1. Gmail アプリで予約メールを探す

ホーム画面のアイコンから開いた状態で：

1. 予約番号の入った立ち寄りの「予約」→「Gmail で予約メールを探す」
2. 「予約番号をコピーしました。Gmail の検索に貼ってください」が出て、Gmail アプリ（受信トレイ）がエラーなしで開くか
3. 検索欄に貼り付けて、予約番号が入るか

## 2. 夫に送るリンクの長さ（要確認）

1. しおりのメニューを開くと、「送る」の下にリンクの長さ（文字数）が出ます
2. 「送る」→ 共有シートで LINE → 自分だけのトークなどに送る
3. LINE でリンクをタップして、しおりが最後のページ（メモ）まで見られるか
4. 「送られたしおり（見るだけ）」の帯が出ているか、持ち物の「リマインダー用にコピー」が使えるか、Gmail ボタンが出ていないか

## 3. ホーム画面から開いたときの外部リンク（要確認）

ホーム画面のアイコンから開いた状態で：

1. 立ち寄りの「地図」→ Google マップのアプリ（なければ Safari）で開くか。しおりに戻れるか
2. 立ち寄りの「サイト」→ Chrome アプリで開くか（送ったしおりの受け取り画面では、ふつうに Safari などで開くか）
3. メモの URL → Safari で開くか
4. メモの電話番号 → 電話をかける確認が出るか

## 4. ページめくりとスクロール・並べ替え（要確認）

1. 左右にスワイプしてページがめくれるか。途中で指を戻すと元に戻るか
2. 予定の多い日で縦スクロールしたとき、勝手にページがめくれないか
3. 持ち物・予定の左の「つまみ（点6つ）」を掴んで並べ替えたとき、ページがめくれないか
4. 右端のタブで、指で押しやすいか（押し間違いが多ければ幅を広げます）
5. 設定 → アクセシビリティ →「視差効果を減らす」をオンにすると、めくりが控えめ（ふわっと切り替わる）になるか

## 5. 開始時刻なしの予定（要確認）

使ってみて要らなければなくします。

## 6. そのほか（パソコンでは確かめられなかったもの）

1. 小窓（予定を編集 など）で文字を入れるとき、キーボードで入力欄が隠れないか
   - キーボードが出たままでも、小窓の右上の「×」で閉じられるか
2. 時刻・日付の入力。入れた時刻を「×」で空にできるか
3. 「リマインダー用にコピー」→ リマインダーのリストに貼って、1行1項目になるか
4. 「全部まとめてバックアップ」→「ファイルに保存」で「ファイル」アプリに保存できるか。そのファイルを「バックアップから戻す」→「ファイルから読む」で読めるか
5. 機内モードにしてホーム画面から開き、しおりが見られるか
6. ダーク／ライトを切り替えて、どちらも読みやすいか（表紙の柄が眩しくないか）
7. 旅行中の日に開くと、今日の行程ページから始まり、「いまここ」の枠が出るか
